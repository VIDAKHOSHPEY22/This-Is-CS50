# 🎓 CS50x Harvard – Projects & Problem Sets

Welcome to my personal repository for **CS50x**, Harvard University's introduction to the intellectual enterprises of computer science and the art of programming.

---

## 📘 About CS50x

CS50x is a rigorous, project-based course that covers the fundamentals of computer science. Throughout this journey, I explored:

- **C Programming**
- **Algorithms & Data Structures**
- **Python**
- **SQL & Databases**
- **Web Development** (HTML, CSS, JavaScript, Flask)

Each problem set challenged my problem-solving skills and deepened my understanding of how software works under the hood.

---

## 🧩 Key Projects

| Project | Description |
|---------|-------------|
| **Hello, World!** | My first C program – a classic start. |
| **Caesar** | Encrypts messages using Caesar's cipher. |
| **Substitution** | Implements a substitution cipher for encryption. |
| **Speller** | A spell-checker that loads a dictionary and checks text files. |
| **Finance** | A full-stack web app for managing a virtual stock portfolio (Flask + SQLite). |

All projects are implemented with clarity, efficiency, and adherence to CS50's style guidelines.
